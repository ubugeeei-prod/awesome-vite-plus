## Development

Use the Node.js version pinned in `.node-version`, pnpm 12, and Vite+. Repository commands are defined as Vite Task entries in `vite.config.ts`.

```sh
vp install
vp run check
vp run format
vp run format:check
vp run lint
```

GitHub Actions installs dependencies with a frozen lockfile and runs `vp run check` on pushes to `main` and pull requests.
